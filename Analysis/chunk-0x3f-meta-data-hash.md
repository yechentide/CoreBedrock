# 0x3F MetaDataHash

## Key

```txt
[chunkX][chunkZ][dimension?][0x3F]
```

## Value

Local notes:

- 8-byte number
- Around Bedrock 1.19: `0x7cb9_b107_e03c_7005`

## Notes

Public references vary in naming around `0x3F`. This document names it `MetaDataHash`.

## Reading Policy

Try reading as `UInt64 LE`, and also preserve a hex dump for display.
